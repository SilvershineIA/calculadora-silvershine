# Calculadora SilverShine 💍

Calculadora de precios de anillos de oro (10k/14k/18k) y plata 925 para [SilverShine](https://silvershine.com.do), Santo Domingo, R.D.

**App en línea:** se publica con GitHub Pages desde este repositorio.

## Funciones
- Precios de oro y plata en línea (api.gold-api.com) y tasa de cambio (open.er-api.com), editables a mano.
- Piedras (diamante, moissanita, zirconia y más) con precios por quilate editables.
- Cotización para el cliente: impresión, PDF descargable y envío por WhatsApp.
- Historial de anillos con estados (Cotizada / Enviada / Vendida / Perdida) y estadísticas.
- Respaldo exportable/importable y exportación del historial a Excel.
- PWA: instalable en el celular y funciona sin conexión.

## Actualizar la app
1. Editar `index.html`.
2. Subir el número de versión en `sw.js` (`silvershine-v1` → `v2`, etc.) para que los teléfonos reciban la versión nueva.
3. Hacer commit y push a `main`.
